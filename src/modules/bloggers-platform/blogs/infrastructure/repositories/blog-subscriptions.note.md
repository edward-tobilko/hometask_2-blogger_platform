# Разбор метода existsByUserAndBlog(...):

Проверяем существует ли уже подписка этого пользователя на этот блог?

# Разбор метода findSubscribersByBlogId(...):

- find({$or: [{ blogId: ... }, {blogId: ...}]}) — находит все документы в коллекции blog-subscriptions где blogId совпадает как по типу string так и по типу ObjectId. Это все записи типа "пользователь X подписан на блог Y".
- new Types.ObjectId(blogId) — конвертируем строку в ObjectId, потому что в MongoDB поле хранится как ObjectId а не строка.
- .lean() — возвращает plain JavaScript объекты вместо Mongoose документов. Нам не нужны доменные методы — только данные, поэтому lean быстрее.
- .map((s) => s.userId) — из каждой подписки берём только userId, остальное не нужно.

Итог: возвращает массив userId всех подписчиков блога, например ["abc123", "def456"]
